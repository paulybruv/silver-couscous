# silver-couscous

## User Case Scenarios

### 1. Start a Game
As a player, I want to start the game so that I can try to guess the Premier League's top goalscorer.

### 2. Make a Guess
As a player, I want to enter a footballer's name so that I can submit my answer.

### 3. Receive Feedback
As a player, I want to know whether my guess is correct or incorrect so that I can see how well I performed.

### 4. Track My Score
As a player, I want my score to update after each guess so that I can track my progress.

### 5. Try Again
As a player, I want to restart the game so that I can play another round.

## Simple Wireframe

```text
+------------------------------------------------+
|        Premier League Top Goalscorer           |
+------------------------------------------------+
|                                                |
|  Who is the Premier League's top goalscorer?   |
|                                                |
|  [ Enter your answer                         ] |
|                                                |
|                 [ Submit Answer ]               |
|                                                |
|  Result: Correct! / Incorrect                  |
|                                                |
|  Score: 1                                      |
|                                                |
|                 [ Play Again ]                  |
+------------------------------------------------+
```

### Page Flow

1. The player reads the question.
2. The player types a footballer's name into the answer field.
3. The player selects **Submit Answer**.
4. The site displays whether the answer is correct or incorrect.
5. The player's score is updated.
6. The player can select **Play Again** to restart.
